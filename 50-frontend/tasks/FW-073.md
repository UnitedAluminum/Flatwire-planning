## 1. What to build

**Hours:** 24 h FE · **Priority:** Medium · **Sprint:** S2 · **Phase:** 6 · **Stream:** FE

**As an** FL1 operator,
**I want** to record a mid-run die change and be forced into an SPC check when the reason demands it,
**So that** a gauge-affecting change is always verified before the run continues.

**Acceptance Criteria:**
- [ ] Built as a `MatDialog` from `../mockups/die_change.js` — `openDieChange(ctx)`, CSS scoped under `.fwdc`, all ids prefixed
- [ ] Select DB1 / DB2 / Both; scan or key the incoming die. ⚠ **`Drawer` now holds exactly those two rows and nothing else** — since the die split it is the draw-**box** register, capped structurally by `CK_Drawer_Name` + `UQ_Drawer_Name`
- [ ] ⛔ **Incoming die validated PER PHYSICAL TOOL against `ToolingInventoryDie`** — an **unregistered** `DieAlpha` (`D-{size×1000}-{seq}`) is rejected, prompting Maintenance to register it. ~~*"Incoming size validated against the `Drawer` 13-row size catalogue — an unrecognised size is rejected"*~~ **is retired: the 13 die-size rows are gone, and `FR-233` / `D4` reverted to their per-tool form on 2 Sep 2026 (`Q91`).** `DieChangeEvent` now carries **`OldDieId` / `NewDieId`** with real FKs, so the check is no longer application-level-only. **`TC-274` is executable for the first time**
- [ ] The incoming die **must match the outgoing die type** (`DieType` — `TC Mono` / `TC Poly` / `Natural diamond`), which the size catalogue could not express
- [ ] Die life read from **`ToolingInventoryDie.LastGrindingFeet` / `TotalFeetAllowed`** — **per tool**, so fitting a fresh die now resets a counter the system can distinguish. ⚠ `TotalFeetAllowed` is **nullable** until the client supplies thresholds: a die without one renders **without a band**, not with a false one
- [ ] Reason: Planned / Gauge drift / Die failure / Size change / Other
- [ ] **Reason = Gauge drift or Size change → opens the SPC checkpoint dialog as a hard gate**, run paused until SPC passes. Close this dialog first, then open SPC
- [ ] Die failure → optional QA hold on the footage range
- [ ] **Suppressed on FL2** — FL2 has no drawing dies
- [ ] Confirm writes the die-change event **plus a linked override**

**Rate-card basis:** modal/dialog 12 h + register validation, life bands and the SPC hand-off 12 h = 24 h (§2). ⚠ **Not re-priced for `Q91`** — the validation target moved, its shape did not; [`FW-258`](../../60-delivery/tasks/FW-258.md) owns any movement
