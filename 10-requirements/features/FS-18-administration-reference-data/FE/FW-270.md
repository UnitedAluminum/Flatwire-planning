## 1. What to build

**Hours:** 12 h FE · **Priority:** Medium · **Sprint:** S2 · **Phase:** 13 · **Stream:** FE

**As a** roll-shop user,
**I want** the *Edgers* option on the Tooling Inventory tab,
**So that** edger sets and their grooves can be maintained like dies.

> ⛔ **THIS STORY OWES AN UN-PRICED MOCKUP**, exactly as `FW-261` does. The 12 h below is the build
> against a mockup that does not exist yet. ⚠ **`[UIC §1.2]` requires the story to name the screen
> and its sections** — do not pick one from the mockup folder.

**Acceptance Criteria:**
- [ ] The *Edgers* option renders the client's **fourteen columns in their order** — the 31 Aug 2026
      grid. ⚠ **Order is part of the requirement**: *"in the order pictured, all others will be removed"*
- [ ] **The gauge grid is a child of the selected set**, not a peer list — `.045` / `.040` / `.035`
      as rows. It must be obvious that a groove belongs to one set
- [ ] Status renders the four lifecycle values — ⚠ **`Active` · `In Service` · `In Grinding` ·
      `Inactive` since 10 Sep 2026 (`D-63`); the fourth was `Retired`.** ⚠ **Do not relabel the die
      screen to match** — `FR-253`'s display band is still `Retired` and
      `DieChangeAndManagement.md` §5 is the single copy. **`In Grinding` is not a boolean** — the narrowness
      `G77` flagged on the old `Edger.IsActive`
- [ ] ⛔ **There is no `Name` field and no alpha** — both were removed from the schema (`G104`), so
      the form asks for neither. A set is shown by `Set Number` + `P/N` + `Machine Name`, which is how
      the client's own grid identifies one. ⚠ **Do not add a display name back** to fill a grid column
      or a dropdown label; compose the label from those three
- [ ] ⛔ **`EdgeType` IS MANDATORY — THIS CRITERION INVERTED ON 10 Sep 2026 (`Q95` leg 5, `D-62`).**
      A set with no profile is **not** valid: the column is `NOT NULL` and a set is ground for
      exactly one profile. ⚠ **The selector offers THREE options, not four** — `Full Round Edge`,
      `Square Edge`, `Broken Edge`. ⛔ **Do not offer `Natural Round Edge` here**; it means *no
      edging*, so it is a schedule value with no tool behind it.
      *(Superseded criterion, retained so the reversal is legible:)* `EdgeType` renders as **optional** — a set with no profile is valid (`D-53`)
- [ ] ⛔ **Straighteners are still out of scope** — `G77`. The tab carries **four** tool types
      (`D-42`) and after this story three of them have screens
- [ ] `[UIC]` supplies the look; consume `lib-nav-rail` / `lib-chart-canvas` from `projects/shared`
      rather than rewriting them. ⚠ **Check a CSS class exists before using it** — `big-screen` still
      does not
- [ ] `/generate-tests` before any spec; `/angular-review` before the PR
- [ ] `[UIC §5]` and this plan updated in the same pass with what was built **and what was skipped**
