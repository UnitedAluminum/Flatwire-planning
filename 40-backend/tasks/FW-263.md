## 1. What to build

**Hours:** 8 h BE · **Priority:** High · **Sprint:** S3 · **Phase:** 1B · **Stream:** BE

> **The project `FW-236` named and could not create.** `FlatWire.sln` is four projects and every one
> is a production project (`G101`). This story creates the fifth and the shared fixtures the four
> suites on top of it all need — it writes **no test of its own beyond a smoke check**, which is why
> it is 8 h and not a suite card.
>
> ⛔ **It is legitimate only because `[TS §1.2]` was reversed first** (`D-50`, 5 Sep 2026). Creating
> it before that reversal is precisely what `FW-N05` declined to do *"from inside a leaf story"*.

**Acceptance Criteria:**
- [ ] `FlatWire.UnitTests/FlatWire.UnitTests.csproj` created, copying `OPCConnection.UnitTests.csproj`: `<IsPackable>false</IsPackable>` and five **unversioned** `PackageReference`s (`Microsoft.NET.Test.Sdk`, `Moq`, `xunit`, `xunit.runner.visualstudio`, `coverlet.collector`)
- [ ] ⛔ **No `TargetFramework` and no `Version=` anywhere** — `API/Directory.Build.props` supplies `net8.0` and central package management, and `API/Directory.Packages.props` is **not modified by this story**
- [ ] ⚠ **`ProjectReference`s use the non-standard csproj FILENAMES** — `..\FlatWire.Domain\Domain.csproj`, `..\FlatWire.Application\Application.csproj`, `..\FlatWire.Infrastructure\Infrastructure.csproj`. ⛔ **`FlatWire.API\Api.csproj` is NOT referenced here** — it belongs to `FW-266`, and it drags Serilog sinks, Swashbuckle, Scrutor and SignalR MessagePack into the test output
- [ ] ⚠ **Do not copy the production projects' `AssemblyName = FlatWire.$(MSBuildProjectName)`** — it would yield `FlatWire.FlatWire.UnitTests`. `<Nullable>enable</Nullable>` **is** set, to match the domain
- [ ] Added to `FlatWire.sln` with `dotnet sln add`, which emits the house type GUID `{9A19103F-16F7-4668-BE54-9A1E7A4F7556}` and Any-CPU-only configurations
- [ ] ⚠ **A four-line `.editorconfig` scoped to `FlatWire.UnitTests/` ONLY**, copying `OPCConnection`'s. ⛔ **Not at the domain root** — FlatWire is the only domain that compiles clean against the full 259-line analyzer set, and that must not be traded away to quiet a test project
- [ ] `Fixture/OpcConnectionStub.cs` — a real `RestClient` over a `Mock<HttpMessageHandler>`, route-aware on `WriteTag`/`ReadTag`/`GetOPCInfo`, **recording every request** so a test can assert none was made. ⚠ The `IHttpClientFactory` returns `new HttpClient(...)` from a **lambda**, not a shared instance
- [ ] `Fixture/FlatWireOpcOptionsBuilder.cs` — a fluent `IOptionsMonitor<FlatWireOpcOptions>` used by four SUTs, with `Simulate(bool)`, `WithoutModule()` (the `G60` default) and `WithoutTag(name)`
- [ ] `Fixture/FakeTimeProvider.cs` — ~20 lines. ⚠ **No package**: `TimeProvider` is in the net8.0 BCL, and `Microsoft.Extensions.TimeProvider.Testing` versions at `8.10.x` beside twenty `8.0.8` pins
- [ ] `Fixture/NoProviderContext.cs` — a `FlatWireDbContext` with **no provider configured**, so a guard-clause test that passes is proof the guard returned before touching the database
- [ ] Shared builders use `[TS §3.3]`'s canonical alphas — `R00041`–`R00043`, `SP-00021`, `PS-1100-FL1-003`, `RUN-0042`/`RUN-0043`
- [ ] ⛔ **Nothing in the project calls `ServiceLocator.Initialise`** — it uses `??=`, so the first test to touch it poisons the whole assembly, order-dependently under xUnit parallelism. A comment in `Fixture/` records this
- [ ] `dotnet build FlatWire.sln` succeeds with **the same production warning count as before** (baseline: 0 errors / 14 warnings), and `dotnet test` runs green
