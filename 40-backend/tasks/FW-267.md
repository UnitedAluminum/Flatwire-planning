## 1. What to build

**Hours:** 10 h BE · **Priority:** Medium · **Sprint:** — *(unscheduled)* · **Phase:** 1B · **Stream:** BE

> ⛔ **This is NOT the withdrawn integration suite, and must not be read as one.** `[TS §1.2]`'s
> *"no integration suite against a seeded `FlatWireDB`"* **stands** (`D-50` reinstates the unit level
> only). This card covers **guard clauses and one generator**, and stops deliberately short.
>
> ⛔ **`CheckInService` (1,165 lines), `RunService`, `SpcService` and `CheckOutService` end-to-end are
> OUT OF SCOPE and deferred** to a future `FlatWire.IntegrationTests` against LocalDB. SQLite cannot
> host them honestly: the model carries **247** T-SQL `HasColumnType` calls (2 are `NVARCHAR(MAX)`,
> which SQLite's DDL grammar rejects), **7** `HasComputedColumnSql` (one is `DATEDIFF(SECOND,…)`),
> and **6** `IsRowVersion`; and `CheckInService.cs:874` Dapper-inserts into
> `[dbo].[PassScheduleChangeLog]`, a table with **no `DbSet`** that `EnsureCreated` never creates.
> A SQLite approximation would be **confidently wrong about exactly the behaviours those services'
> own comments call load-bearing**.
>
> ⛔ **Do NOT extract an `IFlatWireDbContext`.** Seven repositories bind
> `GenericRepository<T, FlatWireDbContext>` — the concrete context is a **generic type argument** with
> a `DbContext` constraint, which an interface cannot satisfy; `MediatorExtension.cs:172` needs
> `ChangeTracker`; and `TransactionBehaviour.cs:99` resolves the concrete type, its own comment at
> `:23` saying it must. The interface would end up being `DbContext` with extra steps.

**Acceptance Criteria:**
- [ ] **Tier 1 — guard clauses, needing no provider at all.** Built on `FW-263`'s `NoProviderContext`: a `DbContextOptions` with **no provider configured**, so a guard test that passes is proof the guard returned *before* touching the database, and the failure mode is loud
- [ ] ⛔ **`GetSpoolsAsync("not-an-alpha")` answers 400, NOT 404** — the service's own remarks call conflating the two *"the mistake to avoid"*. Malformed alpha → 400; well-formed unknown alpha → 404
- [ ] Constructor null-guards on `RunService`, `SpoolService` and `CheckOutService` — `ArgumentNullException` with the correct `ParamName` per parameter
- [ ] **Tier 2 — `BusinessKeyGenerator` against SQLite**, the smallest DbContext consumer (183 lines) and the highest-value untested arithmetic in the domain
- [ ] Exactly **one** new `PackageVersion` line in `API/Directory.Packages.props` — `Microsoft.EntityFrameworkCore.Sqlite` **8.0.8**, on the same patch line as the EF core assembly. ⛔ **Not `EntityFrameworkCore.InMemory`**: it has no transactions, which is the entire mechanism these services are built around, and no relational model — green tests that are confidently wrong
- [ ] `Fixture/SqliteFlatWireDbContext.cs` — a subclass whose `OnModelCreating` strips `HasColumnType`, `HasComputedColumnSql` and `IsConcurrencyToken`, plus `ATTACH DATABASE ':memory:' AS dbo` and views so the `[dbo].[X]` raw SQL resolves. ⚠ **Keep the `SqliteConnection` open for the fixture's lifetime** — the database vanishes with the last connection
- [ ] ⚠ **Every stripped feature is a fidelity loss, and the fixture says so in its own remarks** — this is why tier 3 is deferred, not an incidental convenience
- [ ] Empty table → `RUN-0001`; `RUN-0007` → `RUN-0008`; **an unparseable mark restarts at 1** (`OI-21`); `RUN-9999` **throws**, and the message names `[BR 3]`; all four prefixes covered
- [ ] ⭐ **The mark is read inside an open transaction** — an uncommitted insert is visible to the next `NextRunAlphaAsync` on the same context. This is what justifies the SQLite route at all
- [ ] ⚠ **Always `Mock.Of<IMediator>()`** — `FlatWireDbContext.SaveEntitiesAsync` dispatches domain events before saving, and a real mediator would invoke real handlers
- [ ] ⚠ **Every test states, in its name or a comment, what the provider cannot prove** — no `CHECK` constraint, no unique index, no `ROWVERSION` — so a green run is never mistaken for a constraint check

**Rate-card basis (§2):** not a full service-test card — tier 1 is ~12 guard assertions needing no provider, tier 2 is one 183-line generator plus the SQLite fixture and the one pin = **10 h**. ⚠ The five services end-to-end would be ~36 h and are **deliberately not bought here**
