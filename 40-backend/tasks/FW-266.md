**Acceptance Criteria:**
- [ ] ⭐ **Determinism, the headline.** `[SIM §5.7]` promises the same seed reproduces the same trace tick for tick: two models built with one seed, advanced N ticks, produce **identical** reading sequences; different seeds diverge; and `seed + (int)line` means FL1 and FL2 diverge from each other
- [ ] `TimeProvider` injected at `LineModelBase.cs:478` and `OpcIngestService.cs:696` as an **optional last constructor parameter** defaulting to `TimeProvider.System`, so **no call site and no DI registration changes** and the commit is provably behaviour-preserving. ⚠ Threaded through all three `LineModelBase` subclasses and `LineModelFactory.Create`
- [ ] `LineModelFactory` — each `LineId` yields its own model type; gauge drift under `Steer`; run-state transitions; no `NaN` and no negative footage
- [ ] `OpcConnectionDouble` — **the most test-friendly of the big classes**: not an `IHostedService`, one tick per request. `GetOpcInfo` for known and unknown module ids; `ReadTag(null)` → `BadRequest`; a read advances **exactly one** tick; ⚠ `HostedLines` is **never three** — the `{FL1,FL2}` or `{FL3}` rule
- [ ] `OpcFeedSimulator`'s `ISimLineHost` members tested **synchronously** — `Steer`, `SetRunning`, `DropReadings`, `ApplyScenario`, `InjectFault`, `SetRunState` return `false` for an unhosted line and `true` for a hosted one
- [ ] ⛔ **`StartAsync` is NEVER called.** `OpcFeedSimulator` is a `BackgroundService`; starting it spins a real `PeriodicTimer` publishing into `ReadingChannel` for the life of the test host, which is intermittent hangs and cross-test bleed. `ExecuteAsync` is `protected` — do not reflect into it
- [ ] `SimulatedPushObserver` — forwards all six operations to `inner`; calls `ApplyPush` **only** on a successful push; a failed inner result does **not** reach the models; an `ApplyPush` returning `false` is logged, not thrown
- [ ] `PassSchedulePushPayload` — all six `[PLC §7.2]` value groups present; the right setpoint chosen per component; `ValueDataType` carries `System.Double`/`System.Boolean`/`System.Int32` (never `"double"`); ⚠ **formatting asserted under a `de-DE` culture scope**, because `InvariantCulture` is the documented residual
- [ ] `ConfigurationBinding.LogUnconfirmedTagPaths` covered — ⚠ **this is the only criterion needing `..\FlatWire.API\Api.csproj`**, added on this story and not on `FW-263`
- [ ] `DependencyInjectionRegistry.ReadUseMockData` / `Describe` covered, and ⚠ **both `SimulateOpcFeed` branches asserted** — the flag gates `ISimLineHost` registration in `ConfigurationBinding.cs` and the observer decoration in `DependencyInjectionRegistry.cs`, read independently in two files
- [ ] `FlatWire/README.md` §5 updated in the same change, per `FlatWire/CLAUDE.md`
