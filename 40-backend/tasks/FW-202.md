## 2. The five details

### 2.1 ⛔ The DB 8 h is already spent

Both Orchestration files carry the same warning, and it is worth repeating: **`FW-202`'s DB 8 h
*is* `G38`'s five `FlatWireRun` prompt columns**, deployed 15 Aug 2026. *"Server-owned state,
persisted against the run"* is **literal** — columns, not a table.

⛔ **Do not add a `SpoolCompletionPrompt` table.** `G38`'s resolution considered both and chose
columns because they *"match 'persisted against the run' literally"*.

⚠ **What the DB half still owes is small and real**: `SpoolProcessing.CompletedAt`, which `G49`'s
**B7** identifies and [`FW-244`](../../30-database/tasks/FW-244.md)
supplies — plus **`PromptAnsweredBy`**, the other half of B7's residue.

### 2.2 ⛔ The edge this fires on is dark until `C2`

AC `TC-170`: fires on the **`RUNNING → STOPPED` edge** of `FL{n}.LineState`.

⛔ **`TryMapLineState` returns `false` until commissioning test `C2`.** `FW-150` discovered what
that means and moved its cache invalidation off `LineStatus` for exactly this reason (`P-125`),
and `FW-154`'s `P-181` requires the snapshot to report *unknown* rather than fabricate a state.

**So the primary trigger does not exist yet.** Two consequences:

- **Speed ≈ 0 is listed as corroboration**, but until `C2` it is the **only** available signal —
  and the card does not say it is sufficient alone. ⚠ **Do not silently promote it.**
- **The story cannot be fully demonstrated before commissioning.** Record that, the way
  `FW-205` recorded its inert interlock.

⚠ **`FW-203`'s simulator drives the stop edge**, so the *logic* is exercisable in the trial —
against a synthetic signal whose fidelity is `G39`.

### 2.3 Four independent arming conditions, and this is where off-by-one lives

| Condition | Rule |
|---|---|
| **Armed** | Only while **actual weight ≥ target** — a stop below target raises **nothing** (`TC-169`) |
| **Edge** | `RUNNING → STOPPED`, **an edge, not a level**, re-arming only on a return to RUNNING (`TC-170`) |
| **Dwell** | STOPPED persists a **configurable 5 s default** before display — a jog or thread must not trigger it (`TC-171`) |
| **Suppression** | Suppressed when an open `RunPauseEvent` already captured a **non-spool-removal** reason (`TC-174`) |

⚠ **`FW-205`'s condition 5 shipped off by one** — *"2× the interval is ONE missing reading"* — and
it **blocked a healthy line four seconds after boot**. Only running it found that.

⛔ **Every one of these four has the same shape.** In particular *"exactly once per stop"* needs
persisted state, not an in-memory flag, because the prompt is **durable and re-delivered on
join** — a spurious one outlives the mistake. **`G38`'s columns are that state** (`P-204`'s rule
in `FW-227`, same reasoning).

### 2.4 ⛔ Variance never disables commit

`TC-182` is the criterion most likely to be implemented backwards, because disabling the button
on an out-of-tolerance value is the reflex.

**The specified behaviour:** flag it · show an override panel · **relabel** the button · **keep
the commit control enabled** · offer remote approval. And separately (`TC-183`): an
**incomplete** override flags the missing field, focuses the first, and **commits nothing**.

⚠ **Two different "cannot commit" states, and only one of them is a disabled control** — the
incomplete-override case. **A ±2 % variance with a complete override commits.**

⛔ **The PIN is absent from the payload** (`TC-184`) while both weights, the variance, the
override flag, the supervisor and the reason all persist **regardless of basis**.

### 2.5 The weight basis is `FW-228`'s work, and `Q10` blocks both

`FR-137`'s formula here is the same one
[`FW-228`](FW-228.md) implements: `lb/ft = A × 12ρ`, round-edge
correction, ρ read across. Same reference values — **0.0809 square / 0.0778 round** for 1100 at
0.110″ × 0.625″.

⛔ **Do not implement it twice.** This story **consumes** the converter.

⚠ **One difference to notice**: this card says ρ is read from **`united_db..alloys.alloy_density`
(cross-database)**, while `FW-228` says *"ρ read across from the shared alloy table"*. **Same
source, and it is a cross-database read** — ⚠ note `D-32` removed the shared-schema *migration*,
not the shared-schema *reads*.

⛔ **`Q10` blocks the output of both**, and it is the one open question deliberately carrying no
recommendation. **`[CE §2]`'s 16–32 h reserve applies here as well as on Phase 9.**

## 4. Decisions this plan makes

> `P-##` is continuous across the repository; `P-01`–`P-220` precede this story.

### `P-221` — the prompt ladder's state lives on `G38`'s columns, never in memory

§2.3. The prompt is **durable and re-delivered on reconnect** (`TC-173`), so an in-memory
"already fired" flag re-fires on every restart and the spurious prompt is then **replayed on
join** — outliving the process that made the mistake. `G38`'s five columns exist precisely for
this and are already deployed.

### `P-222` — `OI-25` is resolved before the footage subtraction is written

§3 step 3. `actual = (current footage − footage at spool start)` is only meaningful inside **one**
coordinate system, and `OI-25` records that there are **two**. A subtraction across them yields a
plausible number that is wrong by an offset — **and the weight it produces is what gets printed
on the label.**

**Fallback:** none that is safe. If `OI-25` cannot close, the story must state which coordinate
system it assumes **on the record**, so the error is attributable rather than silent.

### `P-223` — speed ≈ 0 is corroboration and is not promoted to the trigger

§2.2. `TryMapLineState` is dark until `C2`, so the specified edge is unavailable — and the
temptation is to fire on speed alone. ⛔ **The card lists speed as corroboration**, and a
speed-only trigger fires on a jog, a thread and a brief stall, which is exactly what the **dwell**
exists to filter but not what it was tuned against.

⚠ **Demonstrate against [`FW-203`](FW-203.md)'s driven stop edge** and record
the pre-`C2` limitation.

### `P-224` — variance flags and never disables; only an incomplete override blocks

§2.4. Recorded because the reflex implementation is the opposite, and because **two distinct
non-committing states** exist — one of which is a legitimate commit.
